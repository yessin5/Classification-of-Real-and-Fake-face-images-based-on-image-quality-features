🚀 Overview
Identity theft through sophisticated falsification techniques poses serious risks to security and privacy. Although biometric authentication helps, criminals’ ability to generate convincing fake identities remains a major challenge. FIAV (Facial Image Authenticity Verification) addresses this by extracting a rich set of image quality features without requiring any reference image and using them to reliably classify faces as authentic or AI‐generated.

🔍 Key Features
- No-Reference IQA Integration
Combines multiple state-of-the-art image quality assessment methods to capture diverse visual artifacts and distortions.

- Comprehensive Feature Extraction
Gathers metrics describing sharpness, noise, compression artifacts, color fidelity, and more.

- Robust Classification
Leverages these quality features in a machine‐learning pipeline to achieve high accuracy in discriminating real vs. AI‐generated faces.

- Interactive Web Interface
Built with Streamlit for easy upload, real-time inference, and instant feedback on any new image.
